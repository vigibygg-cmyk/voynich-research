Reproducibility & Transparency

Data & Code

Open science requires open data. Here you will find the complete toolkit required to independently verify, replicate, and challenge the findings of the 118-phase replication study.

§ 01 · Execution

How to Run
(Step-by-Step)

You do not need a local Python environment to test the core computational findings. You can independently verify the data using a personal Google Colab session with zero configuration.

01. Open Colab: Navigate to Google Colab and create a new, blank Python notebook.
02. Download Data: Download the specific Python scripts from the sections below, alongside the cleaned IVTFF transcriptions (RF1b, ZL3b, IT2a) from Voynich.nu.
03. Upload to Workspace: In Colab, open the left-hand panel, click the folder icon ("Files"), and upload the downloaded `.txt` and `.json` data files directly into your temporary session workspace.
04. Execute: Paste the script code into a Colab cell and press `Shift + Enter` to run. The script will automatically parse the uploaded files and reproduce the exact Pointwise Mutual Information (PMI) clustering, Truncated SVD, and entropy calculations shown in the results.

§ 03 · Python Scripts

Computational
Algorithms

The following are foundational scripts from the 118-phase study. The full suite of algorithms covers BPE valency mapping, SVD clustering, generative Markov chains, and Cross-Corpus Isomorphic Translation.

phase_01_data_extraction.py Downloads & Standardises IVTFF files (removes inline comments, normalizes spaces). 
# VOYNICH MANUSCRIPT: DATA EXTRACTION SCRIPT (PHASE I)
# Target Environment: Google Colab

import urllib.request
import urllib.error
import os
import re

OUTPUT_DIR = "voynich_clean_data"
TARGET_FILES = ["RF1b-er.txt", "ZL3b-n.txt", "IT2a-n.txt"]

def clean_voynich_text(raw_text):
    """ Removes IVTFF metadata, brackets {}, and standardises spaces. """
    text = re.sub(r'\{.*?\}', '', raw_text)  # Remove inline comments
    text = re.sub(r'[\.,]', ' ', text)      # Dots/commas to spaces
    text = re.sub(r'[-=\*%|]', '', text)     # Remove uncertainty markers
    return re.sub(r'\s+', ' ', text).strip()
phase_04_edge_bias_analysis.py Calculates positional distribution of tokens at physical line edges (Edge Bias). 
# VOYNICH MANUSCRIPT: EDGE BIAS ANALYSIS (PHASE IV)
# Identifies tokens co-generated with illustration boundaries.

def calculate_edge_bias(lines):
    edge_counts = {}
    mid_counts = {}
    
    for line in lines:
        tokens = line.split()
        if len(tokens) < 3: continue
        
        # Tally edges (first and last token)
        edge_counts[tokens[0]] = edge_counts.get(tokens[0], 0) + 1
        edge_counts[tokens[-1]] = edge_counts.get(tokens[-1], 0) + 1
        
        # Tally internal tokens
        for t in tokens[1:-1]:
            mid_counts[t] = mid_counts.get(t, 0) + 1
            
    return edge_counts, mid_counts
